# Multi-Wordle 研究專案

用 Godot 4 .NET 開啟 `project.godot`，按 **F5** 進入主選單。也可以在此目錄執行 `dotnet build` 編譯 C#。

- 可選 1、4、8、16 個盤面，分別有 6、9、13、21 次猜測。每局從 `word_list.json` 抽出不重複的答案，同一份題庫也用來驗證輸入。
- 用實體或螢幕鍵盤猜詞，每個有效猜測會套用到所有尚未解出的盤面。畫面一次顯示一個大盤面；點擊編號按鈕或按 Tab／Shift+Tab 切換。盤面可用滾輪捲動，輸入時會回到最新一列。
- AI 對每個未解盤面採候選等機率假設。先按全局單步 Shannon 資訊熵挑出 15 字，再從該前 15 字與各回饋分支仍可能的答案選出最佳第二步，按 `H₁ + E[H₂]` 與收斂、直接解盤獎勵排序。畫面上的 bits 不含獎勵；多盤時，各盤的第二步最佳值相加，是此評估詞池下對共享第二猜的上界，而非精確的聯合策略。內建字庫有預算的開局結果；更換字庫後會在背景重算。
- AI 面板最多顯示三顆推薦鍵帽；有盤面只剩唯一解時，優先且只顯示這類答案。點擊可填入單字，仍須自行送出。焦點盤面的 `Ω` 是剩餘候選數；`S = log₂ Ω` 是以 bits 表示的狀態熵。
- AI 面板以三欄兩列顯示焦點盤面機率最高的六個字母，僅在剩餘 20 個候選單字以下時列出所有候選。字母機率是「至少出現一次」的候選比例，不必合計為 100%。切換焦點不會重算全局排名。
- 右下角 `SOUND` 開關控制程式合成的輸入、刪除、有效送出與全數破關提示音，無需外部音檔。

`Scripts/Core/` 包含題庫、回饋編碼、候選過濾與平行求解；`Scripts/UI/` 和 `Scenes/` 分別放介面腳本及場景。若從 Godot 匯出遊戲，請在匯出預設的非資源檔案包含篩選器中加入 `word_list.json, opening_recommendations.json`。
