# Multi-Wordle & Information Entropy AI Solver

基於 **Godot 4 (.NET / C#)** 開發的多聯動猜字遊戲與**資訊熵（Shannon Information Entropy）決策輔助實驗平台**。本專案支援 1 至 16 盤面同步聯動挑戰，並透過高效能演算法即時計算全局最佳推薦單字與候選字庫字母機率分佈。

---

## 核心特色與系統功能

### 1. 多聯動盤面機制（`N + 5` 步數規則）
* **四種難度模式切換**：支援 **1 聯**（經典 Wordle，6 步）、**4 聯**（Quordle，9 步）、**8 聯**（Octordle，13 步）與 **16 聯**（Sedecordle，21 步）。
* **全合法字庫驗證**：內建 `14,855` 個五字母英文單字庫（`word_list.json`），題庫與合法輸入驗證共用相同範圍，確保遊戲公平性與完整搜尋空間。
* **多盤面聚焦與快速切換**：透過右側數字按鈕或 `Tab` / `Shift + Tab` 快捷鍵，即時切換檢視任意盤面狀態與剩餘候選字數。

### 2. AI 資訊熵決策輔助引擎（`EntropySolver`）
* **全局總資訊熵計算**：針對所有尚未破關的盤面，即時計算每個合法單字的預期資訊增益（\(H = -\sum p \log_2 p\)），推薦能同時為最多盤面提供最大線索的 Top 5 單字。
* **殘局唯一解鎖定機制**：當任一盤面縮小至僅剩 1 個唯一候選答案時，系統自動優先鎖定並推薦該解答，避免步數浪費。
* **候選字庫字母機率統計**：即時統計目前焦點盤面剩餘候選字中，各英文字母（A–Z）的覆蓋出現機率，輔助玩家進行推理決策。
* **實驗對照開關**：支援在開始介面自由啟用或停用 AI 輔助功能，便於進行「人機協作」與「純人類決策」之對照實驗。

## 核心效能優化設計

為了確保在 **16 聯動模式**下同時過濾與計算 `14,855` 個單字仍維持流暢幀率（60 FPS），後端核心採用了三項底層優化：
1. **三進位模式編碼（Base-3 Pattern Encoding）**：將 5 格的灰／黃／綠回饋壓縮為 `0 ~ 242`（3⁵ = 243）的單一 byte 整數，大幅降低比對與分桶計數的記憶體開銷。
2. **漸進式候選字庫過濾（Progressive Filtering）**：每個盤面獨立維護剩餘候選單字索引清單，隨回合推進呈指數級縮小搜尋空間。
3. **多執行緒平行運算（`Parallel.For`）**：利用 C# 多核心平行處理各單字之資訊熵累加計算，實現毫秒級即時推薦回應。

## 專案架構

```text
wordle-1/
├── project.godot               # Godot 4 .NET 專案設定檔
├── word_list.json              # 14,855 筆五字母英文單字庫
├── start_menu.tscn             # 開始介面場景（難度與 AI 輔助設定）
├── game.tscn                   # 主遊戲與 AI 分析實驗場景
└── Scripts/
    ├── Core/                   # 純 C# 核心演算法層（與前端 UI 解耦）
    │   ├── GameConfig.cs       # 全域設定與 N+5 步數規則
    │   ├── WordRepository.cs   # 字庫讀取與三進位 Pattern 高速比對
    │   ├── BoardLogic.cs       # 單一盤面狀態機與候選字動態過濾
    │   └── EntropySolver.cs    # 資訊熵推薦引擎與字母機率統計
    └── UI/                     # Godot 前端介面控制層
        ├── StartMenu.cs        # 開始介面控制
        ├── GameController.cs   # 主遊戲流程、鍵盤互動與分析面板更新
        └── WordleBoardUI.cs    # 盤面視覺渲染元件
```

## 環境需求與執行方式

1. **開發環境**：
   * [Godot Engine 4.x (.NET 版本)](https://godotengine.org)
   * [.NET SDK 8.0 或以上版本](https://microsoft.com)
2. **啟動步驟**：
   * 下載或 Clone 本專案至本機。
   * 開啟 Godot .NET 編輯器，點擊 **匯入（Import）** 並選擇 `wordle-1/project.godot`。
   * 點擊右上角 **建置（Build）** 編譯 C# 專案後，按下 **F5** 即可開始執行。

---

## 操作說明

* **輸入單字**：使用實體鍵盤（`A–Z`、`Backspace`、`Enter`）或點擊畫面下方虛擬鍵盤；亦可直接點擊右側 AI 面板的推薦單字卡片自動填入。
* **切換盤面**：點擊盤面右側的數字按鈕（`01–16`），或按 `Tab` 切換至下一個未破關盤面。
